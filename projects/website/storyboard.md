# Ein Klick. Eine Webseite.

| Zeit | Erkenntnis | Sichtbare Veränderung |
|---|---|---|
| 0–2,9 s | Ein Klick löst das Laden aus. | Der Zeiger klickt auf die Schaltfläche im Browser. |
| 2,9–6,1 s | Der Browser fragt beim Server an. | Der Bildausschnitt öffnet sich. Ein Anfragepaket läuft zum Server. |
| 6,1–9,4 s | Der Browser erhält Dateien. | HTML, CSS und JS kommen als schematische Dateipakete zurück. |
| 9,4–14 s | Aus Ressourcen entsteht die Darstellung. | Struktur und Gestaltung erscheinen als Ebenen und schließen sich zur Webseite. |

Keine vollständige Netzwerksimulation: DNS, TLS, Caching und zusätzliche Ressourcen sind hier ausgelassen. JavaScript ist nicht für jede Webseite erforderlich. Mehrere tatsächliche Datei-Anfragen werden visuell zusammengefasst.
