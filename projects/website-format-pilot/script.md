# Textentwurf

Noch keine erzeugte Stimme. Ein möglicher Erklärtext, falls eine gesprochene Fassung gewünscht wird:

Du klickst auf eine Website. Wie wird daraus das Bild auf deinem Bildschirm? Der Browser findet zuerst den passenden Server. Dabei hilft das Domain Name System wie ein Adressbuch. Dann schickt der Browser eine Anfrage. Als Antwort kommen Daten zurück: zum Beispiel HTML für die Struktur, CSS für das Aussehen und JavaScript für mögliche Reaktionen. Der Browser verarbeitet diese Bestandteile und setzt die Seite zusammen. Texte bekommen ihren Platz, Farben erscheinen, Bilder werden sichtbar. Und wenn Code ein Menü steuert, kann es auf deinen Klick reagieren. Der Server liefert also Daten. Dein Browser macht daraus die Website, die du siehst.

Für eine stumme Fassung werden daraus kurze Objektlabels: „Adresse finden“, „Anfrage“, „Dateien“, „Struktur“, „Gestaltung“, „Interaktion“ und die Schlussaussage. Keine langen Untertitelblöcke als Ersatz für die gezeigte Erklärung.
