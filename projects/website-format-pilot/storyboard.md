# Vollständiger Filmplan: Vom Klick zur Website

Ziel ungefähr 48 Sekunden. Die Zeiten sind Planung, keine bereits aufgenommene Sprecher- oder Schnittspur. Die reine Animation muss auch ohne Stimme verständlich bleiben. Kein neues Video wurde für diesen Plan gerendert.

| Zeit    | Neue Information                                                    | Hauptobjekt und konkrete Veränderung                                                                                                                     | Übergang                                                  |
| ------- | ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| 0–4 s   | Frage: Was steckt hinter einem Klick?                               | Eine eigene fertige Beispielseite ist kurz sichtbar. Ein Klick lässt ihre sichtbaren Elemente in einzelne Bausteine auseinandergehen.                    | Aus der Adresszeile wird das nächste Hauptobjekt.         |
| 4–10 s  | Der Browser braucht den passenden Server.                           | Ein Adressbuch ordnet einen Domainnamen einer Serveradresse zu. Die gefundene Adresse leuchtet grün.                                                     | Der ausgewählte Eintrag wird zum Ziel auf einem Umschlag. |
| 10–17 s | Anfrage und Antwort verbinden Browser und Server.                   | Ein Umschlag reist zum Server. Dessen Schublade öffnet sich und zeigt Dateien.                                                                           | Die Dateien treten aus der Schublade ins nächste Bild.    |
| 17–25 s | Eine Seite besteht aus verschiedenen Bestandteilen.                 | Drei verständliche Objekte: HTML als Struktur/Bauplan, CSS als Gestaltung, JavaScript als mögliche Interaktion. Kurze Rollenlabels statt langer Absätze. | Der Bauplan klappt zu einem Browserfenster auf.           |
| 25–34 s | Der Browser setzt die Darstellung zusammen.                         | Strukturblöcke ordnen sich an, die Gestaltung legt sich darüber und Bilder füllen ihre Plätze.                                                           | Der Blick fährt in ein fertig aufgebautes Bedienelement.  |
| 34–41 s | Code kann Reaktionen ermöglichen.                                   | Ein Klick auf ein Beispielmenü öffnet es. Ein kurzer JavaScript-Impuls macht den Zusammenhang sichtbar.                                                  | Herausfahrt zur vollständigen eigenen Beispielseite.      |
| 41–48 s | Auflösung: Daten kommen an, das sichtbare Bild entsteht im Browser. | Die fertige Seite entspricht dem Einstiegsbild. Zwei bis drei kleine Objektspuren der Reise verbinden sich mit ihr und verschwinden.                     | Klarer Schluss: „Dein Browser baut das Bild.“             |

Modellgrenzen: stark vereinfachter erfolgreicher Seitenaufruf. Caches, CDNs, Verschlüsselungsaufbau, parallele Anforderungen und Details der Browser-Engine sind nicht als vollständiger Netzwerkablauf dargestellt. JavaScript ist keine Voraussetzung für jede Website. Die Bildfolge darf nicht behaupten, der Server sende grundsätzlich ein fertiges Screenshot-Bild.
